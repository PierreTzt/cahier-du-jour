# Le journal de conception

Ce qui suit a été écrit au fil de l'usage réel, dans la famille où l'outil
est né : chaque écran, chaque règle, et surtout **pourquoi** ils sont ainsi.
Beaucoup de décisions viennent d'un retour des parents un soir, ou d'une
journée qui s'est mal passée ; elles sont datées et racontées comme telles.

Si vous ne lisez qu'une page, lisez la première.

1. **[Les règles de conception](regles.md)** — les onze règles qui
   conditionnent tout ce que l'enfant voit. Elles priment sur le reste.
2. **[Les écrans](ecrans.md)** — ce que voit l'enfant, ce que voient les
   adultes, et qui lit quoi.
3. **[Le programme et la trame](programme.md)** — le manuel, la correction,
   l'année jour par jour, le ton du jour, les fiches, le calendrier.
4. **[Le test de positionnement](positionnement.md)** — ce que l'enfant sait
   en arrivant, sans jamais savoir s'il a juste.
5. **[L'entrée](entree.md)** — les codes, les sessions, et pourquoi on ne
   verrouille jamais.
6. **[Le système visuel](visuel.md)** — le papier Seyès, les couleurs, les
   contrastes mesurés.
7. **[Développer](developper.md)** — les commandes, les tests, les outils de
   relecture du manuel.
8. **[Les limites](limites.md)** — ce qui n'est pas fait, et ce qu'il faut
   savoir avant de s'en servir.

Pour l'installer : [la marche à suivre](../deploiement/README.md).
